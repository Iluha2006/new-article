# СМАРТ-КВИК — news-раздел (статический сайт)

Чисто статический сайт: только HTML + CSS + один небольшой JS. Сборщиков и серверных технологий нет.

## Структура проекта

```
.
├── index.html            ← страница «Новости» (карточки + фильтр по категориям)
├── news/                 ← 29 страниц статей (1 статья = 1 файл)
│   └── <slug>.html
├── css/
│   └── style.css         ← все стили сайта
├── images/               ← готовые фотографии (соответствие файлов — в images/README.md)
│   ├── conditioning.jpg      ← общее фото для статей про кондиционеры
│   ├── ventilation.jpg       ← общее фото для статей про вентиляцию
│   ├── refrigeration.jpg     ← общее фото для статей про холодильное оборудование
│   └── … (уникальные фото по объектам)
└── js/
    └── main.js           ← см. «Зачем нужен js» ниже
```

## Фото: принцип «один файл — много статей»

Однотипные статьи (например, все про обслуживание кондиционеров) используют
одно и то же фото из `images/` — отдельный снимок на каждую статью не нужен.
Уникальные фото (2-й ЗОВС, Щёлковская больница, Управа Старое Крюково,
спорткорпуса, детсад, учебные корпуса) подключены точечно.

Полная таблица «файл ↔ статьи» — в `images/README.md`.

## Зачем нужен js/main.js

Скрипт небольшой и подключён через `defer`, сайт работает и без него, но он делает три вещи:

1. **Заглушки для фото** — если какого-то изображения ещё нет в `images/`,
   вместо «сломанной картинки» показывается аккуратный серый блок с подписью.
   Когда вы положите файл с нужным именем — всё переключится автоматически.
2. **Фильтр новостей по категориям** на `index.html` (кнопки «Все / Пищеблоки /
   Холодильное оборудование / Кондиционирование / Вентиляция»).
3. **Бургер-меню** на мобильных + текущий год в подвале.

Если фильтр и бургер-меню не нужны, а заглушки больше не требуются
(все фото на месте) — файл `js/main.js` и его `<script>` в HTML можно удалить.

## Как добавить новую фотографию

1. Положите файл в `images/` (латинское имя без пробелов, JPEG, ~1200–1600 px по ширине).
2. В нужной странице `news/<slug>.html` замените `src` у обложки
   (и `og:image` в `<head>`) на путь к новому файлу, поправьте `alt`.
3. Для дополнительного фото внутри статьи продублируйте блок
   `<figure class="article-photo photo">…</figure>`, указав свой `src`, `alt`
   и подпись в `<figcaption>`.

Единственная статья без своего фото — «ТО пароконвектоматов в ИКБ №1»:
положите файл `images/to-parokonvektomatov-ikb1-cover.jpg`, и заглушка
заменится автоматически (в HTML ничего менять не нужно).

## Что правится вручную

- Телефон и e-mail: найдите по сайтам `+7 (495) 000-00-00` и
  `info@smart-quick.ru` (подвал и блок «Позвонить» в статьях).
- Даты публикации: `<time datetime="…">` в шапке каждой статьи и в карточках.
- Пункты меню «Услуги / О компании / Контакты» — сейчас `href="#"`,
  замените на реальные страницы, когда появятся.

## Локальный просмотр

```bash
python3 -m http.server 8000
# открыть http://localhost:8000/
```
(или просто открывайте файлы двойным кликом — сайт работает и по file://)
