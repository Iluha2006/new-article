## Без фото (пока заглушка)

- `to-parokonvektomatov-ikb1.html` — «ТО пароконвектоматов в ИКБ №1».
  Положите файл `images/to-parokonvektomatov-ikb1-cover.jpg` (1200×675) —
  заглушка заменится автоматически.

## Технические заметки

- Имена файлов — латиница без пробелов (безопасно для URL и любых хостингов).
- Все изображения — JPEG, 1536×1024 или 1024×1024, вес 180–400 КБ.
- В карточках и статьях фото кадрируется в блок 16:9 через CSS (`object-fit: cover`),
  поэтому квадратные снимки отображаются корректно.
